# 건지울른스

영국 건지섬의 피셔맨 니트에서 영감을 받은 헤리티지 울 가디건 브랜드의 한국어 정적 홈페이지입니다.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저에서 열거나 간단한 정적 파일 서버로 실행하면 됩니다.

```powershell
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 파일

- `index.html` — 홈과 브랜드·제품·이야기·연락 콘텐츠
- `about.html` — 인터뷰를 바탕으로 쓴 1인칭 내 소개 페이지
- `products.html` — `products.json`의 전체 제품을 보여주는 제품 페이지
- `products.json` — 제품명, 가격, 이미지 주소, 구매 링크 데이터
- `styles.css` — 디자인과 반응형 레이아웃
- `script.js` — 모바일 메뉴, 스크롤 상태, 폼 안내
- `assets/` — 생성된 브랜드 이미지

제품 가격, 이메일, 인스타그램 주소, 블로그 링크와 구독 전송 기능은 출시 정보에 맞게 교체해야 합니다.

새 제품은 `products.json` 배열에 항목을 추가하면 홈에는 앞의 3개, 제품 페이지에는 전체가 자동으로 표시됩니다. `purchaseUrl`이 비어 있으면 구매 버튼 대신 `구매 준비 중`으로 표시됩니다.
